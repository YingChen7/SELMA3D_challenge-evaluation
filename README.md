### Evaluation metrics in SELMA3D challenge

For  dot-like structures, for example cells and cell nuclei, we evaluate the segmentation results using 2 metrics:
- volumetric Dice similarity coefficient;
- Betti error in dimension 0.

For tree-like structures, for example blood vessels, we evaluate the segmentation results using the following 4 metrics:
- volumetric Dice similarity coefficient;
- Betti error in dimension 0;
- Betti error in dimension 1;
- centerline Dice similarity coefficient.
